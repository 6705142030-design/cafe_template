# ☕ Hearth & Bean Café

A modern, warm cafe landing page with animated steam effect, built with pure HTML & CSS.

## ✨ Features

- 🎨 Warm, modern design with coffee-inspired color palette
- 💨 Animated steam SVG illustration
- 📱 Fully responsive (mobile friendly)
- 🎯 Smooth scroll navigation
- 🍰 Menu/services section
- ⭐ Why choose us section
- 📍 Contact section with hours
- ⚡ Zero dependencies, pure HTML/CSS

- HTML5

- Custom SVG illustrations

Coffee shops, bakeries, and cafes wanting a premium online presence.
